## 2. Why the bubbles had to be rebuilt

The Sprint 3 "i" markers used the HTML `title` attribute. The browser draws
those tooltips itself, so a web page cannot give them a border or change how
they look; request 2 was impossible with that approach. The markers now carry
their text in a hidden element that the page's CSS shows on hover. A side
benefit: the bubble also opens when a keyboard user tabs to the "i", which a
`title` tooltip does not.

Streamlit's own help bubbles are restyled rather than replaced, so the form
fields keep their built-in help behaviour. Streamlit sizes its bubble before
placing it, so only its colours, border, corners and width are changed; the
page's own bubble copies Streamlit's padding and text size instead of the
other way round.

## 3. Edge cases checked

* **Streamlit versions.** Streamlit 1.50 draws the help icon directly; newer
  releases wrap it in a button. The CSS targets the element both share, and
  screenshots from 1.50 and 1.67 are identical.
* **Screen edges.** Every bubble on the page (12 after a run) was opened at
  390px, 1024px and 1400px wide; none extended off screen. Bubbles in the
  right-hand column open leftwards; on phone-width screens bubbles sit across
  the bottom of the screen.
* **Keyboard.** Both kinds of bubble open on keyboard focus.
* **Uppercase labels.** The result tiles use uppercase labels; the bubble
  resets this so its text is not shouted.
* **Escaping.** Bubble text is escaped like all other page HTML; a test
  injects markup into a glossary entry and checks it is neutralised.

## 4. Merge with `main`

The Sprint 3 branch (`dashboard-sprint3`) had not been merged, and `main` had
since added prerequisite checks for the memory and tool cases to
`services/dashboard/app.py`. That one file conflicted. The resolution keeps
the Sprint 3 layout and carries the checks into it: a case that cannot run in
the current configuration shows a "Not run - <reason>" warning above the
buttons and its Submit button is disabled, exactly as on `main`. Javon's two
tests for this pass unmodified.
